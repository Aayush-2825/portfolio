# Aayush Raj Portfolio

A dark blueprint-editorial portfolio for Aayush Raj, a full-stack developer and Technical Co-founder of DOZO.

The V2 concept, "The Full Stack, Literally", will show full-stack breadth through real project data and a Layer Map covering Interface, API, Data, Realtime, Security, and Infrastructure.

## Stack

- Next.js App Router
- React and TypeScript in strict mode
- Tailwind CSS
- Motion via `motion/react`
- Bricolage Grotesque, Geist, and Geist Mono through `next/font`

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npx tsc --noEmit
npm run lint
npm run build
```

All portfolio claims are sourced from `data/*.ts`. Unknown values remain marked with TODO comments and are omitted from the rendered UI.
